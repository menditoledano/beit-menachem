# shul-seats

מערכת מכירת מקומות שנתית לבית הכנסת חב"ד "בית מנחם", גני איילון.

מפה חיה של האולם, בחירת מקום עצמית על ידי המתפלל, וגיליון Google קיים כבסיס הנתונים.

## מבנה

| נתיב | מה יש שם |
|---|---|
| `app/` | Next.js — המפה הציבורית, מסך הגבאי, ונתיבי `api/` שמשמשים פרוקסי |
| `apps-script/` | קוד השרת. נפרס ל-Google Apps Script בעזרת clasp, ויושב ב-git כדי שיהיה ניתן לסקירה |
| `lib/domain.ts` | טיפוסי פרוטוקול משותפים ולוגיקת תמחור ונרמול טלפון |

## למה שתי שכבות שרת

Apps Script הוא היחיד שיכול לנעול את הגיליון נעילה אמיתית (`LockService`), ולכן הוא כותב.
אבל אפליקציית web של Apps Script מריצה כל בקשה אנונימית **בתור בעל הסקריפט**, והמכסה היא
30 הרצות במקביל לחשבון. מאה אנשים שמרעננים מפה כל שלוש שניות שוברים את זה.

הפרוקסי ב-Next.js סופג את הקריאות במטמון עם single-flight, כך ש-Apps Script רואה קריאה אחת
כל כמה שניות ללא קשר לכמות הצופים. בנוסף הוא מחזיק את כתובת ה-`/exec` ואת הסוד מחוץ לדפדפן,
ומוסיף את מה ש-Apps Script לא יכול לראות בכלל — כתובת IP ו-headers.

## התקנה

```bash
nvm use 26              # ברירת המחדל במערכת היא node 16, ישנה מדי ל-clasp
npm install
cp .env.example .env.local
```

## פריסת קוד השרת

```bash
npm run gas:login       # פעם אחת, פותח דפדפן
npm run gas:push
```

> **אזהרה:** עדכון גרסה חייב להיעשות דרך *Manage deployments → עריכה → New version*.
> יצירת *deployment* חדש מייצרת כתובת `/exec` חדשה, ומשתנה הסביבה `GAS_URL` מת באותו רגע.

## פיתוח

```bash
npm run dev
```

## תפעול בזמן מכירה

הכל נשלט מטאב `_Config` בגיליון:

- `MODE` — `OPEN` / `READONLY` / `CLOSED`. `READONLY` הוא בלם החירום: עריכת תא אחד מקפיאה את המכירה תוך פחות מדקה.
- `PHASE` — `A` לסבב החזקה, `B` לסבב הפתוח. המעבר הוא פעולה מפורשת של הגבאי ולא טיימר, כדי שלא יקרה בלילה בלי שאף אחד שם לב.
